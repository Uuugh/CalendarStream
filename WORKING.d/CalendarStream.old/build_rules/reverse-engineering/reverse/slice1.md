# Slice 1: setup, sign-in, lockouts, Settings, updates, page frame

Notes: "page login" = the single user name + password protecting the status page. "Setup code" is printed in the container log. Backup and restore are not features of the app (see section 3, R1-30).

## 2. Failed-sign-in lockouts, global block, recovery link

Terms: "failed attempt" = one wrong sign-in, wrong first-visit setup code, wrong Basic credentials, or wrong current password in Settings. "Address" = the client's network address as seen by the app (proxy headers are not consulted). Time values are exact.

## 3. Settings (domains, login, administrator e-mail, time zone, backup, logo/favicon, theme)

All Settings posts need a signed-in session (R1-10) and a valid form token (R1-15). The Settings panel (opened by the ☰ button, title "Settings") has these groups in this order: Login & password, Domains, Updates, Theme, Google Calendar API Sync (outside this slice). In Full page mode the same settings are reached from a side list with headings Configure (Calendars, Feeds, All Rules, Event Templates, History), User (Login & password) and Site Admin (Domains, Updates, Theme, Google Calendar API Sync), each opening its own pop-up with a Back button; the content of each setting is identical in both layouts.
