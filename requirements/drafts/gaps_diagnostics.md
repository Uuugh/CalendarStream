## Coverage and limitations

10 owned rows, each with one New outcome, reconciled into 15 proposals DIA-05–DIA-19 after current DIA-04. Compound rows retain explicit disposition of historical compatibility and regression-only fragments.

Report redaction concerns the prepared shared report; diagnostic access to the original calendar file remains subject to page authentication and is not a promise that every raw debug file is safe to publish. No real data or credentials are included. GitHub replies and issue-following are provider behavior, not new CalendarStream delivery guarantees. Shared form, preview-layer and clipboard feedback mechanics are not repeated. No application suites were run locally for this documentation-only change.
