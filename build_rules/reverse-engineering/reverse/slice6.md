# Slice 6: History, diagnostics, monitoring interfaces, installation and deployment, shared building blocks

Notes: "page" = the status page. "Source" = a calendar source (United CCS+ with ID `ccs`, a feed, or a local calendar). "Display zone" = the time zone the page's calendar is shown in. "Server zone" = the TZ setting. Times quoted as "HH:MM" are 24-hour unless written with am/pm. Where the Python code and a visible text disagree the visible text is quoted. "unsure" marks ambiguous code.
